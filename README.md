# 群会话开启助手（astrbot_plugin_conversation_opener）

列出机器人加入的全部群聊，标出哪些群还没有「活跃对话」；在插件页面里勾选，
即可为这些群创建对话。

## 为什么需要它

AstrBot 的**主动回复**（可能性回复等方式）必须挂在群已有的**活跃对话**上才能发出。
一个群如果从没人 @ 过机器人、也没人跟它聊过，这个群就没有活跃对话——主动回复
就算掷中概率也发不出去，日志会反复报：

```
No active conversation is available for proactive replies
```

逐个群发 `/new` 太麻烦，改数据库又要停服。本插件把这件事变成点一下按钮。

## 使用

1. 在 AstrBot 面板「插件」页找到 **群会话开启助手**，进入插件详情；
2. 打开 **groups** 视图；
3. 列表按「未开启在前」排序，每个群带群名、群号、成员数和状态徽章；
4. 勾选未开启的群（或点「全选未开启」），点击「为勾选的群开启会话」。

开启是即时生效的，不需要重启。开启只给缺对话的群新建空对话，已有对话的群
不会被动到。

## 关闭会话

勾选已开启的群（或点「全选已开启」），点击「关闭勾选群的会话」，再点一次确认。
关闭会**删掉该群当前的对话**（上下文清空），该群随即回到「未开启」状态：
机器人不再在该群主动回复；需要时随时可以再开启（重新开启得到的是一个空对话）。
适合：不想让机器人在某些群主动说话，或想给某个群换一段干净的上下文。

## 原理

- 群列表：通过 OneBot 协议的 `get_group_list` 获取（目前支持 aiocqhttp 平台）；
- 状态判断：`ConversationManager.get_curr_conversation_id(umo)` 是否有值；
- 创建对话：调用官方 `ConversationManager.new_conversation`，与内置 `/new`
  指令走同一入口，同时写入数据库与内存中的会话指针。

## 环境要求

- AstrBot `>=4.16,<5`（用到插件可视化视图与 `astrbot.api.web`）；
- 消息平台为 aiocqhttp（QQ）；机器人未登录时页面会提示读取失败。
